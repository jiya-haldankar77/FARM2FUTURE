## 🎓 Technical Details

### Language Detection
- Checks `localStorage.getItem('voiceGuideLanguage')`
- Defaults to 'en' if not set
- Synchronized across all pages

### Voice Synthesis
- English: `en-US` language code
- Hindi: `hi-IN` language code
- Prefers female voices
- Fallback to system default

### Transcript Updates
- Dynamic content switching
- Real-time translation
- Segment highlighting
- Auto-scroll to active
