## 🔧 Customization Guide

### Change Voice Script
Edit the `segments` array in each JS file:

```javascript
this.segments = [
  {
    id: 'your-id',
    text: "Your custom message...",
    duration: 5000,
    focus: 'your-section-class'
  }
];
```

### Change Widget Color
Edit the `addStyles()` method:

```javascript
.voice-btn {
  background: linear-gradient(135deg, #YOUR_COLOR_1, #YOUR_COLOR_2);
}
```

### Update Focus Sections
Edit the `focusSection()` method:

```javascript
case 'your-section':
  element = document.querySelector('.your-class');
  break;
```

## 🐛 Troubleshooting

### Common Issues

**Widget not appearing:**
1. Check Font Awesome is loaded
2. Verify script is loaded after DOM
3. Check browser console for errors
4. Refresh the page

**No audio playing:**
1. Use Chrome, Edge, or Safari
2. Check system volume
3. Click on page first (browser security)
4. Verify Web Speech API support

**Wrong content playing:**
1. Check correct script is loaded
2. Verify page-script mapping
3. Clear browser cache

**Sections not highlighting:**
1. Update CSS selectors
2. Check class names match
3. Verify elements exist
