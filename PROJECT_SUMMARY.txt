========================================
🔌 API ENDPOINTS:
========================================

Authentication:
POST   /api/login          - User login
POST   /api/logout         - User logout
GET    /api/check-session  - Check if authenticated

Crops:
GET    /api/crops          - Get all crops
POST   /api/crops          - Add new crop

Tasks:
GET    /api/tasks          - Get all tasks
POST   /api/tasks          - Add new task
PUT    /api/tasks/:id      - Update task status

Analytics:
GET    /api/analytics      - Get analytics data
POST   /api/analytics      - Add analytics data

Activities:
GET    /api/activities     - Get recent activities
POST   /api/activities     - Log new activity
POST   /api/seed-activities - Add sample activities (testing)

📊 DATABASE STRUCTURE:
========================================

farmer table:
- farmer_id (PK)
- name
- email (unique)
- password
- created_at

crops table:
- crop_id (PK)
- farmer_id (FK)
- crop_name
- crop_type
- sowing_date
- location
- created_at

tasks table:
- task_id (PK)
- farmer_id (FK)
- task_name
- status (Pending/Completed)
- due_date
- created_at

analytics table:
- analytics_id (PK)
- farmer_id (FK)

- rainfall_status
- irrigation_status
- temperature
- created_at

activity_log table:
- activity_id (PK)
- farmer_id (FK)
- activity_type
- description
- timestamp

========================================
🐛 TROUBLESHOOTING:
========================================

Problem: Can't connect to database
Solution: 
- Check MySQL is running
- Verify password in server.js
- Ensure database 'farm_dashboard' exists

Problem: Unauthorized errors
Solution:
- Clear browser cookies
- Login again
- Check session configuration

Problem: Activities not showing
Solution:
- Click "Add Sample Data" button
- Or add a crop to generate activity
- Check database has data

Problem: Port 5000 in use
Solution:
- Change PORT in server.js line 309
- Or stop other process using port 5000
